# Hangman Game

Консольная реализация игры **Виселица** на языке Go.

Проект сделан в рамках учебного роадмапа по Go backend-разработке.  
Цель проекта - потренироваться в базовом синтаксисе Go, работе с файлами, консольным вводом/выводом и простым игровым циклом.

## Описание игры

Игра на английском

При запуске приложение предлагает начать новую игру или выйти.

Если пользователь начинает игру, программа случайно выбирает слово из файла `words.txt`.  
Игрок должен угадывать слово по одной букве.

После каждого хода программа показывает

- текущее состояние слова
- сообщение о правильной или неправильной букве
- количество ошибок

Игра заканчивается, если:

- игрок полностью угадал слово
- игрок допустил 7 ошибок
